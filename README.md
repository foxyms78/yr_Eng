# 영어 자습 노트

고2 영어 자기주도 학습용 모바일 웹앱입니다. GitHub Pages로 배포하고, 학습 기록은 구글 시트에 저장합니다.

- **첫 화면**: 2학기 기말 대비 / 수능 필수 단어 중 선택
- **오늘**: 단어 · 구문 · 문제 체크, 한 줄 메모
- **단어**: Day별 외우기(뜻 가리기), 4지선다 퀴즈(영→한, 한→영), 최근 7일 오답 복습
- **이번 주**: 요일별 체크 현황, 퀴즈 평균, 연속 일수, 주간 메모, 엄마 한마디

## 폴더 구조

```
index.html
css/style.css
js/config.js          ← Apps Script URL, 기말고사 날짜 설정
js/data-suneung.js    ← 수능 필수 단어 300 (Day 1~10)
js/data-final.js      ← 기말 범위 단어 (현재 비어 있음)
js/app.js
apps-script/Code.gs   ← 구글 시트에 붙여넣을 스크립트 (GitHub Pages에는 쓰이지 않음)
```

## 1. 구글 시트 만들기

1. 새 구글 스프레드시트를 만듭니다. (예: `영어 자습 노트 기록`)
2. 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장합니다.

## 2. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 > 새 배포**
2. 유형 선택: **웹 앱**
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. 배포 후 권한 승인 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. `js/config.js`의 `SCRIPT_URL`에 붙여넣습니다.

> 코드를 수정한 뒤에는 **배포 > 배포 관리 > 수정(연필) > 버전: 새 버전**으로 다시 배포해야 반영됩니다. 새 배포를 만들면 URL이 바뀌니 주의하세요.

시트 탭 `학습기록`, `엄마한마디`는 첫 저장 때 자동으로 생깁니다.

## 3. GitHub Pages 배포

1. 개인 GitHub 계정에 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. 저장소 **Settings > Pages > Source: Deploy from a branch**, 브랜치 `main` / 폴더 `/ (root)` 선택
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 주소로 열립니다.

딸 휴대폰에서 이 주소를 열고 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.

## 엄마가 기록 보는 법

- 구글 시트 `학습기록` 탭: 날짜별 체크(✓), 퀴즈 기록, 틀린 단어, 메모
- 앱의 **이번 주** 탭에서도 같은 내용을 볼 수 있습니다.
- `엄마한마디` 탭에 주 시작일(월요일, `2026-10-12` 형식)과 내용을 직접 적어도 앱에 표시됩니다.

## 기말 단어 넣기

`js/data-final.js`의 `days`에 Day별 문자열을 넣으면 첫 화면에서 바로 열립니다.

```js
days: [
  "word|뜻;word|뜻;...",   // Day 1
  "word|뜻;word|뜻;..."    // Day 2
]
```

`js/config.js`의 `FINAL_EXAM_DATE`에 시험 시작일을 넣으면 첫 화면에 D-day가 표시됩니다.

## 참고

- 시트 연결이 안 되거나 오프라인이어도 기록은 휴대폰에 먼저 저장되고, 다음에 앱을 열 때 시트로 다시 보냅니다.
- 공개 저장소에 올리면 `SCRIPT_URL`도 공개됩니다. 주소를 아는 사람은 기록을 읽고 쓸 수 있으니, 저장소 주소를 널리 공유하지 않는 것을 권합니다. (학습 기록 외 개인정보는 저장하지 않습니다.)
